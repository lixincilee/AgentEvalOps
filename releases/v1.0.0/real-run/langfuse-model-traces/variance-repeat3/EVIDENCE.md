# 真实模型 `--repeat 3` 方差证据（2026-10-20）

## 1. 这次补的是什么

此前 310 条真实模型 trace 和 16 条成功切片都只跑了一次，只能说明「这一轮是什么结果」，
不能回答「同一份用例再跑一次会不会翻转」。本次用同一份 60 条分层切片、同一套判分和同一版本
代码，背靠背跑 3 次，记录通过率、延迟、token、花费和逐用例结论的极差。

**结论**：本轮 v2 / v3 的通过率均为 **98.3%**，3 次极差 **0.0 个百分点**；
`flaky_cases` 为空，没有跨轮翻转。唯一失败固定为 `v2_err_unsupported_04`。
这只能说明**本轮切片未见抽样噪声**，不是置信区间，也不能外推成稳定失败率。

## 4. 口径边界

- 60 条是四类各 15 条的**分层切片**，不代表 213 条总体；它用于补方差，不替代全量回归。
- 3 次重复只给出**本轮观测极差**，不是置信区间，也不能把 98.3% 当成稳定失败率。
- RAG 48 条没有纳入本次切片；本次不覆盖检索质量方差。
- 模型温度为 0.0，但供应商实现、缓存和网络延迟仍可能带来成本/延迟波动。
- 通过率极差为 0 不代表未来不会翻转；要估计稳定失败率需要更多重复或更大样本。
