## 口径

- 重复报告的通过率取中位数，最差一次单独判；两者都过才算通过。
- 任何框架错误行都阻断：那是「没测出来」，不是「分数低」。
- 容忍值来自当前样本量下的实测方差，不是统计显著结论；夜间跑得越多越该收紧。
